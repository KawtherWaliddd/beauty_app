#  Beauty App 💅

## 🚀 Features
-  **Login & Signup** with Firebase Auth  
-  **Home** – Recent & popular products  
-  **Categories** – Browse all categories  
-  **Profile** – Manage user info  
-  **App Info & Contact Developer**  
-  **Dio** for API integration  
-  **Modern & responsive UI**

---

## 🛠️ Built With
- **Flutter** & **Dart**  
- **Firebase Auth**  
- **Dio (HTTP Client)**
