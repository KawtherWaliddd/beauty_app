#  Beauty App 💅

A **Flutter beauty application** that lets users browse products, explore categories, and manage profiles with a clean and modern interface.  
Built using **Flutter**, **Dio**, and **Firebase Auth** as part of my **ITI final project**.

## 🚀 Features

-  **Firebase Authentication** (Login & Signup)  
-  **Home** – View featured and recent beauty products  
-  **Categories** – Explore all categories and items  
-  **Profile** – Manage user info  
-  **App Info** & 📞 **Developer Contact** pages  
-  **Dio** – API integration  
-  **Responsive UI** for Android & iOS  

---

## 🛠️ Tech Used

- **Flutter**  
- **Dart**  
- **Firebase Auth & Firestore**  
- **Dio (HTTP Client)**
